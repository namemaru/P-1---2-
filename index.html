ทบทวนก่อน แล้วลองทำข้อสอบดูนะ

เลือกหน่วยที่อยากติว อ่านสรุปสั้น ๆ แล้วทำข้อสอบ 10 ข้อ มีทั้งเลือกตอบ ถูก–ผิด เติมคำ เรียงลำดับ และจับคู่ เหมือนใบงานในห้องเรียน ตอบแล้วรู้เฉลยทันทีพร้อมคำอธิบาย ทุกข้อมีคำแปลภาษาอังกฤษกำกับ และมีเสียงอ่านโจทย์ทั้งไทยและอังกฤษ

ใส่ชื่อก่อนนะ ครูจะได้เห็นคะแนนของหนู

ไม่มีเสียงภาษาไทยให้เลือก ทำอย่างไร
ลองข้อนี้ก่อน — ถ้าเปิดหน้านี้อยู่ในแอป Claude ให้กดเมนูแล้วเลือก เปิดในเบราว์เซอร์ (Safari หรือ Chrome) เพราะหน้าจอในแอปบางเครื่องเข้าถึงเสียงของระบบไม่ได้
iPhone / iPad
  1. ตั้งค่า → การช่วยการเข้าถึง → เนื้อหาที่พูด
  2. เลือก เสียงพูด (Voices) → ไทย
  3. เลือกเสียง Kanya แล้วกดปุ่มดาวน์โหลด
  4. กลับมาเปิดหน้านี้ใหม่ใน Safari
Android
  1. การตั้งค่า → ระบบ → ภาษาและการป้อนข้อมูล → เอาต์พุตการอ่านออกเสียง
  2. เลือกเครื่องมือ Speech Recognition & Synthesis จาก Google
  3. กดรูปเฟือง → ติดตั้งข้อมูลเสียง → ไทย → ดาวน์โหลด
  4. กลับมาเปิดหน้านี้ใหม่ใน Chrome
Windows — วิธีที่เร็วที่สุด
  1. คลิกขวาที่ไฟล์เว็บนี้ → Open with → Microsoft Edge
  2. Edge มีเสียงไทย Premwadee และ Niwat ให้ใช้ทันที ไม่ต้องติดตั้งอะไร (ต้องต่ออินเทอร์เน็ต)
Windows — ถ้าอยากใช้ Chrome หรือใช้ตอนไม่มีเน็ต
  1. Settings → Time & language → Language & region → Add a language → ไทย
  2. หน้าถัดไป ติ๊ก Text-to-speech ให้ครบ แล้วกด Install
  3. Windows 10 ใช้ Settings → Time & Language → Speech → Manage voices → Add voices → ไทย
  4. ปิดเบราว์เซอร์แล้วเปิดหน้านี้ใหม่
Mac
  1. System Settings → Accessibility → Spoken Content → System Voice → Manage Voices
  2. เลือก Thai → Kanya → ดาวน์โหลด
  3. เปิดหน้านี้ด้วย Safari
